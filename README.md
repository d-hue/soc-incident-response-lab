# SOC Incident Response Lab

## Overview

Hands-on cybersecurity investigation focused on Windows endpoint monitoring, Sysmon telemetry analysis, suspicious process investigation, persistence detection, DNS analysis, and network activity correlation.

This project demonstrates a practical Security Operations Center (SOC) investigation workflow using a simulated Windows endpoint in a controlled TryHackMe environment.

---

## Investigation Scenario

A suspicious executable, `ckjg.exe`, was downloaded and executed on a Windows endpoint.

I analyzed Sysmon telemetry to reconstruct the activity and identify indicators associated with potential malware execution, persistence, and external network communication.

### Investigation Flow

**Download → Execution → Persistence → DNS Resolution → Network Communication**

## Investigation Techniques

### Process Analysis

Reviewed Sysmon process creation events to identify suspicious executable activity and command-line information.

### Persistence Analysis

Investigated file creation events and identified a file created within the Windows Startup directory.

### DNS Analysis

Correlated DNS queries generated by the suspicious process with subsequent network activity.

### Network Analysis

Reviewed Sysmon network connection events to identify external communication initiated by the suspicious executable.

### Timeline Reconstruction

Correlated multiple Sysmon event types to reconstruct the sequence of activity across the endpoint.
